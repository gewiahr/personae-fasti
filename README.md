# personae-fasti

**Personae** - серия модулей-помощников для настольных ролевых игр.

**Fasti** - модуль, предназначенный для ведения хронологических заметок по играм. Модуль представляет из себя API-сервис с подключением к базе данных, предназначенный в первую очередь для развёртки в Docker-контенере.
